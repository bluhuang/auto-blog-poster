关于这个站
与自动化彩蛋

这个博客是全自动生成的——我写了一套自动化博客发布工具， 名叫 auto-blog-poster。我只需要在 Obsidian 里写笔记， 推送后几分钟，博客就自动更新了。

01

监听 Obsidian

笔记仓库一旦推送，自动触发流水线。

02

AI 润色

调用 DeepSeek API 优化文字表达。

03

处理特殊语法

转换 Obsidian 图片和链接语法。

04

增量更新

只处理新增或修改的笔记，避免重复。

05

构建并部署

生成静态站点并发布到 GitHub Pages。

支持分类卡片、树形导航、搜索、评论和数学公式。 项目源码与博客示例都保持公开可访问。
